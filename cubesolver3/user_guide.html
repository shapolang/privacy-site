2x2魔方速解使用说明

更新日期：2026年11月1日

【2x2魔方速解】是一款面向 2x2 魔方爱好者的解算与练习工具。您可以手动涂色录入魔方状态，查看分步还原公式和 3D 演示，也可以自由玩魔方、使用竞速计时器记录成绩。本说明将帮助您快速上手。

一、首次启动与账号登录

1. 首次打开应用时，会先显示《隐私政策》和《用户协议》页面。请阅读后点击“同意”；您也可以点击页面中的链接查看完整隐私政策、用户协议和使用说明。点击“不同意”将退出应用。

2. 同意隐私政策后，应用才会初始化 TapTap 登录并拉起授权页面。请使用 TapTap 账号授权登录；如取消登录，应用会提示完成登录和实名认证后才能继续使用。

3. 登录后，应用会通过 TapTap 合规认证完成实名认证与防沉迷校验。身份证件信息由 TapTap 处理，本应用仅获取年龄段和剩余可游戏时长等结果。

4. 如您已完成实名认证，后续启动通常会自动恢复登录状态。如需更换账号，请先在 TapTap 客户端退出或切换账号，或通过本说明第十条的联系方式联系我们。

二、3D 涂色录入魔方

本应用采用 3D 涂色方式录入 2x2 魔方，不需要拍照，也不会调用相机。

  1. 旋转视角：在 3D 魔方区域拖动，调整观察角度，使屏幕中的魔方朝向与您手中的真实魔方一致。
  2. 选择颜色：点击需要涂色的贴纸，再在颜色选择器中选择白色、黄色、绿色、蓝色、橙色或红色。
  3. 建议涂色顺序：当前页面 → 右边 → 右边 → 右边 → 上面 → 下面。每涂完一面，旋转到下一面继续。
  4. 检查数量：一个合法的 2x2 魔方共有 24 个可见贴纸，每种颜色恰好 4 个，不能有未涂色的灰色贴纸。
  5. 保存并解算：涂色完成后点击底部的“确定”按钮。校验通过后，应用会保存当前魔方状态，并进入解算与演示页面；下次打开时会自动恢复上次保存的涂色。
  6. 重新录入：点击重置按钮可以清空当前涂色，重新开始。
如果提示“无效魔方”或“有缺失的面块”，请依次检查：24 个贴纸是否全部涂满、每种颜色是否恰好 4 个、3D 视角是否与真实魔方朝向一致、同一角块上是否出现了两种相对颜色。

三、查看解法与 3D 演示

1. 解算完成后，页面会显示原始打乱序列和解算序列。序列中的字母对应魔方的标准转动记号，例如 R、U、F 及其带撇号的逆时针转动。

2. 您可以使用“上一步”“播放/暂停”“下一步”按钮逐步查看每一次转动，3D 魔方会同步演示。也可以拖动魔方从不同角度观察。

3. 长按序列文本可以复制，方便您在其他设备或练习页面中使用；也可以截图保存后反复练习。

4. 解算结果仅供参考，请以您实际魔方的状态和转动结果为准。如果结果与预期不符，请返回检查涂色和朝向是否准确。

四、自由玩魔方

1. 在首页点击“玩魔方”进入自由练习页面。

2. 拖动魔方可以旋转视角；拖动魔方表面可以转动对应层。页面会实时统计转动步数和用时。

3. 点击“打乱”会先恢复到已还原状态，再随机打乱魔方；点击“重置”可以恢复为已还原状态，并清零步数和计时。

五、竞速计时器

1. 在首页点击“计时器”进入计时页面。计时器支持历史成绩、最佳成绩、AO5（五次平均）和 AO12（十二次平均）。

2. 不使用观察时间时：按住屏幕任意位置，松开后开始计时；计时过程中点击任意位置停止。

3. 开启 15 秒观察时间时：按住并松开开始观察；观察结束后再次按住并松开开始计时。观察超时可能被判 +2 或 DNF，具体以页面提示为准。

4. 每次计时结束后，可以使用 +2、DNF 标记本次成绩，或删除本次成绩。点击“清空”会清除当前会话的历史成绩，操作前会再次确认。

5. 点击“换一个”可以生成新的随机打乱公式；点击“自由”可以打开自由打乱编辑器，通过 R、R2、R'、L、U、D、F、B 等按钮添加转动步骤，支持撤销和重置，点击“完成”后应用该打乱。

六、用激励视频撤销惩罚

1. 当某次成绩被标记为 +2 或 DNF 后，页面会提供“看广告撤销”按钮。每条成绩通常只能使用一次撤销机会。

2. 首次点击时，应用会展示广告隐私说明。只有在您点击“同意并继续”后，才会初始化 TapADN 广告 SDK 并请求激励视频。

3. 完整观看视频并通过奖励验证后，本次惩罚会被撤销。若您关闭或跳过视频、播放失败、网络异常或奖励验证未通过，惩罚不会被撤销，您可以稍后重试。

4. 如果您不同意广告隐私说明，或不希望观看广告，可以继续使用魔方解算、自由玩魔方和计时等基础功能，只是无法使用广告撤销。

七、数据保存与清除

  1. 上次涂色的魔方状态、计时成绩、观察时间设置和广告隐私同意状态保存在您的设备本地。
  2. 清除应用数据或卸载应用会删除上述全部本地数据，且无法恢复。
  3. 退出 TapTap 登录或注销账号后，相关账号服务可能无法继续使用，但本地魔方和计时数据仍会保留，直至您主动清除。

九、常见问题

1. 提示“无效魔方”怎么办？
请确认 24 个可见贴纸全部涂满、每种颜色恰好 4 个、3D 视角与真实魔方朝向一致，并检查同一角块上是否出现两种相对颜色。修正后重新点击“确定”。

2. 解算结果和我的魔方不一致怎么办？
通常是涂色顺序或魔方朝向不一致导致的。请重置后，按照“当前页面 → 右边 → 右边 → 右边 → 上面 → 下面”的顺序重新涂色，并在涂色前先把 3D 视角调整到与真实魔方一致。

3. 登录失败或无法进入应用怎么办？
请检查网络连接，确认已安装并登录 TapTap，然后重试。如仍未解决，请通过下方邮箱联系我们并提供设备型号、系统版本和问题截图。

4. 广告加载失败或看不了广告怎么办？
广告可用性受网络、广告库存和地区影响。请稍后重试，或检查网络连接。广告不可用不会影响基础功能，但本次惩罚可能无法撤销。

5. 换手机后成绩还在吗？
计时成绩和涂色状态仅保存在本机，不会自动同步到新设备。更换设备前请自行记录重要成绩。
