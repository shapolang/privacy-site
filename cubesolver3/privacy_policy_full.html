2x2魔方速解隐私政策

更新日期：2026年11月1日

云梦山水工作室系移动应用程序“2x2魔方速解”（Android 包名：com.lihuamao.cubesolver.d2.pro，以下简称“本应用”或“我们”）的运营者。我们非常重视保护用户（以下简称“您”）的个人信息和隐私。您在使用本应用时，我们会收集、使用、保存、共享您的相关个人信息。为呈现我们处理您个人信息的情况，我们特制定《2x2魔方速解隐私政策》（以下简称“本政策”），我们承诺严格按照本政策处理您的个人信息。

我们在此提醒您：在您使用本应用前，请您务必认真阅读本政策，充分理解各条款内容，包括但不限于免除或限制我们责任的条款。您知晓并确认，您勾选“同意”本政策并使用本应用，即表示您同意我们按照本政策处理您的个人信息。本政策仅适用于我们通过本应用向您提供服务所收集的信息，不适用于通过接入本应用向您提供产品或服务的第三方所收集的信息。第三方的处理规则见其各自的隐私政策。

本隐私政策将帮助您了解以下内容：

  3. 三、我们如何使用 Cookies 和同类技术
  4. 四、我们如何共享、转让、公开披露您的个人信息

一、我们如何收集和使用您的个人信息

（一）我们如何收集您的个人信息

在您使用本应用过程中，我们会按照如下方式收集您的个人信息：

1. 账号登录
您可以使用 TapTap 账号登录本应用。登录时，我们会从 TapTap 获取账号标识（OpenID、UnionID）、昵称和头像，用于识别您的游戏账号并保持登录状态。我们不另行收集您的手机号码、登录密码或身份证件号码。本应用在启动时会自动拉起 TapTap 登录；如您不登录，将无法进入本应用。

2. 实名认证与防沉迷
为履行网络游戏防沉迷的法定义务，我们通过 TapTap 合规认证服务核验您的真实身份与年龄。身份证件信息由 TapTap 按照其隐私政策处理，我们仅获取年龄段、剩余可游戏时长等防沉迷结果，不在本应用内单独保存您的姓名、身份证件号码或人脸信息。如您不完成实名认证，将无法继续使用本应用。

3. 魔方解算与游戏记录
本应用的核心功能是 2x2 魔方的涂色录入、解算和步骤演示。您通过 3D 涂色录入的魔方状态、保存的魔方数据、计时器成绩与历史记录、观察时间设置、广告隐私同意状态等，仅保存在您设备的应用私有存储中，不会上传至我们的服务器。您可以在应用内重置魔方、清空成绩，或通过清除应用数据、卸载应用删除上述信息。

4. 可选激励视频广告
本应用在计时器页面提供“看广告撤销”功能，用于撤销一次 +2 或 DNF 惩罚。只有您主动点击该按钮，并首次同意应用内单独的广告隐私说明后，我们才会初始化 TapADN 广告 SDK。广告 SDK 为实现广告请求、展示、监测归因、反作弊、效果统计和稳定性保障，可能收集设备品牌与型号、操作系统版本、屏幕信息、语言与时区、网络类型与网络状态、IP 地址、广告展示/点击/关闭等交互数据，以及崩溃和性能数据。我们已通过 SDK 隐私配置关闭其对精确定位、粗略定位、电话状态/IMEI、Wi-Fi 状态（含 BSSID、SSID）、外部存储写入、应用安装列表、Android ID、MAC 地址、传感器信息和 OAID 的主动读取。拒绝同意广告隐私说明不会影响魔方解算、自由玩魔方和计时等基础功能，但无法使用广告撤销功能。当前版本不提供应用内支付，不收集支付账号和支付记录。

5. 反馈与客服
当您通过“反馈”入口主动发送邮件时，您的邮件地址、邮件正文及您主动附带的截图或信息将被发送至我们的联系邮箱，用于处理您的咨询、意见或投诉。您可以选择不发送反馈，这不影响其他功能的使用。

6. 保障网络和服务的安全
在您登录、完成实名认证或请求广告时，相关服务会通过互联网传输必要的数据。为保障服务安全和稳定，TapTap SDK 和 TapADN SDK 可能处理设备信息、网络信息和日志信息，具体范围以本政策第五条所列第三方隐私政策为准。

（三）我们如何使用您的个人信息

1. 我们会根据本政策的约定，为实现账号登录、实名认证与防沉迷、魔方解算、计时记录和可选广告等功能，对所收集的个人信息进行使用。

2. 请您注意，您在使用我们提供的服务时所提供的所有个人信息，除非您删除或通过系统设置拒绝我们收集，否则将在您使用我们的服务期间持续授权我们使用。在您注销账号或删除相关信息后，我们将停止使用并依法删除或匿名化处理。

3. 我们会对我们提供的服务使用情况进行统计，并可能会与公众或第三方共享不含身份识别信息的统计信息，用于产品开发、服务优化和安全保障。

4. 当我们要将您的个人信息用于本政策未载明的其他用途，或基于特定目的收集而来的信息用于其他目的时，会事先征求您的同意。

5. 广告相关信息仅用于广告请求、展示、监测归因、效果统计、反作弊和安全保障。如广告服务涉及个性化推荐，您可以通过本政策第十条的联系方式要求关闭；关闭后您仍可能看到广告，但与您的相关程度会降低。

（四）其他规则

根据相关法律法规及国家标准，以下情形中，我们可能会收集、使用您的相关个人信息而无需征求您的授权同意：

  1. 与我们履行法律法规规定的义务相关的；
  2. 与国家安全、国防安全直接相关的；
  3. 与公共安全、公共卫生、重大公共利益直接相关的；
  4. 与刑事侦查、起诉、审批和判决执行等直接相关的；
  5. 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人授权同意的；
  6. 所涉及的个人信息是个人信息主体或监护人自行向社会公众公开的；
  7. 根据个人信息主体要求签订和履行合同所必需的；
  8. 从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开等渠道；
  9. 维护所提供产品或服务的安全稳定运行所必需的，如发现、处置产品或服务的故障。

二、我们如何保存您的个人信息

1. 我们将在本政策载明的目的所需及法律法规要求的最短保存期限之内，保存您的个人信息。前述期限届满后，我们将对您的个人信息做删除或匿名化处理。

2. 您在设备本地产生的魔方状态、计时成绩和设置数据，保存在本应用的私有存储中，直至您主动清除应用数据或卸载应用。如您开启了设备的系统云备份功能，上述数据可能由设备厂商或系统备份服务按照其隐私政策进行备份，该备份行为不受我们控制。

3. 我们在中国境内运营过程中收集和产生的个人信息将保存在中国境内（为本政策之目的，“中国境内”不含中国港澳台地区），以下情形除外：

  1. 法律有明确规定；
  2. 获得您的明确授权；
  3. 您要求获取境外服务等个人主动行为。

针对以上情形，我们会确保依据本政策以及相关法律规定对您的个人信息提供足够的保护。

三、我们如何使用 Cookies 和同类技术

1. 本应用本身不使用浏览器 Cookies。为保存魔方状态、计时成绩、观察时间设置和广告隐私同意状态，本应用会使用 Android SharedPreferences 等本地存储技术。上述本地数据仅保存在您的设备上，不会用于跨应用追踪。

2. TapTap SDK 和 TapADN SDK 可能使用本地标识或同类技术实现登录状态保持、广告识别、归因和统计。第三方合作伙伴通过 Cookies 或同类技术收集和使用您的信息不受本政策约束，而受其自身隐私政策约束，我们不对第三方的 Cookies 或同类技术承担责任。

3. 您可以通过清除应用数据或卸载应用删除本应用保存在本地的全部数据。删除后，魔方涂色状态、计时成绩和广告同意状态将无法恢复。

四、我们如何共享、转让、公开披露您的个人信息

1. 委托处理

我们会委托第三方服务提供商处理实现登录、实名认证、防沉迷和广告功能所必需的个人信息。上述委托处理行为受本政策中所声明目的约束，并且我们会以合同或平台规则的方式对受托的第三方服务提供商进行监督。

2. 共享

(1) 事先获得您明确的同意或授权，或您要求我们通过电子邮件或其他方式与第三方共享您的个人信息；

(2) 根据适用的法律法规规定，或按照政府主管部门的强制性要求进行提供；

(3) 与我们的关联公司共享：我们可能会与我们的关联公司共享您的个人信息，但只会共享必要的个人信息，且受本政策中所声明目的的约束；关联公司也将依据本政策采取同等的安全保障措施；

(4) 与业务合作伙伴共享：为完成 TapTap 登录、实名认证与防沉迷，我们会向易玩（上海）网络科技有限公司提供实现对应功能所必需的信息；为展示可选激励视频广告，我们会在您单独同意后向上海艾得蒽数字科技有限公司的 TapADN SDK 提供或由其收集实现广告功能所必需的信息。

3. 我们不会出售您的个人信息，也不会将您的个人信息用于本政策未载明的目的。

六、我们如何保护您的个人信息

我们采取包括传输加密、访问控制、最小化收集等措施保护您的信息安全，并在发生安全事件时依法通知您和监管部门。TapTap SDK 和 TapADN SDK 仅在实现对应功能所必需的范围内使用。广告 SDK 仅在您单独同意广告隐私说明后初始化；如您拒绝，我们不会初始化广告 SDK。请您理解，互联网并非绝对安全的环境，任何安全措施都无法做到万无一失，请妥善保管您的设备和账号信息。

七、您如何管理您的个人信息

1. 访问与更正：您可以在应用内查看已保存的魔方状态、计时成绩和设置；如需访问或更正账号相关信息，可以通过本政策第十条的联系方式与我们联系。

2. 删除：您可以通过应用内的重置、清空成绩功能清除当前显示的魔方涂色和成绩；通过清除应用数据或卸载应用，可以删除本地保存的全部信息。对于账号相关信息，可以通过本政策第十条的联系方式要求删除。

3. 撤回同意：您可以通过设备系统设置关闭本政策所列权限，或在应用内拒绝广告隐私说明，以拒绝相应信息的收集。撤回同意不影响撤回前基于您的同意已进行的个人信息处理活动的效力。

4. 注销账号：您可以通过 TapTap 平台管理或注销 TapTap 账号，也可以通过本政策第十条的联系方式申请注销与本应用相关的账号信息。注销后，我们将停止使用并按法律规定删除或匿名化您的个人信息。

5. 关闭个性化广告：如广告服务涉及个性化推荐，您可以通过本政策第十条的联系方式要求关闭。关闭后您仍可能看到广告，但广告与您的相关程度会降低。

八、我们如何处理未成年人的个人信息

本应用主要面向能够独立操作魔方的用户。若您是未满 18 周岁的未成年人，请在监护人陪同下阅读本政策，并在取得监护人同意后使用我们的服务。我们通过 TapTap 合规认证履行网络游戏防沉迷要求，并按照法律规定保护未成年人的信息安全。如果我们发现在未获得可证实的监护人同意的情况下收集了未成年人的个人信息，会尽快删除相关信息。监护人如对未成年人的个人信息有疑问，可以通过本政策第十条的联系方式与我们联系。

九、本隐私政策如何更新

本政策会在本页面发布更新，重大变更会通过应用内提示或其他显著方式通知您，未经您的明确同意不会削减您依据本政策享有的权利。当第三方 SDK、设备权限或个人信息处理目的发生变更时，我们会同步更新本政策第五条和权限说明。
